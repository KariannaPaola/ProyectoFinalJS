Rick and Morty Characters App

Aplicación web que consume la API pública de Rick and Morty para mostrar personajes de la serie.
Permite explorar personajes y guardar tus favoritos usando LocalStorage, para mantenerlos incluso después de recargar la página.

Live Demo
https://kariannapaola.github.io/ProyectoFinalJS/

Tech Stack
Javascript
Tailwind CSS
Rick and Morty API
LocalStorage (persistencia en el navegador)

Features
Visualización de personajes obtenidos desde la API de Rick and Morty.
Listado dinámico de personajes con información básica.
Posibilidad de agregar personajes a favoritos.
Persistencia de favoritos usando LocalStorage.
Eliminación de personajes de la lista de favoritos.
Interfaz simple y fácil de usar.

What I Learned
Consumo de APIs REST 
Uso de LocalStorage para persistencia de datos en el navegador.
